# ColemakMods

Mods and ideas for Colemak and other optimized keyboard layouts.

Created and maintained by **Steve P** ([@stevep99](https://github.com/stevep99)).

## Projects

- **[Colemak Mod-DH](https://github.com/ColemakMods/mod-dh)** – the "Colemak-DH" layout,
  a Colemak mod for more comfortable typing. [Colemak-DH Home page](https://colemakmods.github.io/mod-dh/)
- **[Ergonomic mods](https://github.com/ColemakMods/ergonomic-mods)** – keyboard
  modifications for increased efficiency and ergonomics.
- **[Colemak Mod-DH Keyboard for Android](https://f-droid.org/packages/io.github.colemakmods.mod_dh/)** –
  use Mod-DH with a physical USB keyboard on Android.
